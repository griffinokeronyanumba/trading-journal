# Using the journal — quick guide

**First time:** Accounts → New account → set starting balance, currency, risk per trade, limits. Then Instruments (add contract specs if you want automatic P&L), Settings (session times, grades, mistake tags, confluences, setups) and Strategies (rules + required confluences).

**Logging a backtest session fast:** New trade → fill in → **Save & add another** (keeps account, instrument, direction, strategy, risk). **Ctrl/⌘ + Enter** saves. On any trade, **Duplicate** copies the plan. Paste chart screenshots on the trade page with **Ctrl+V**.

**The account selector** (top bar) controls every page. "All accounts" combines accounts without mixing currencies (switches to R when currencies differ).

**Numbers:** R = net P&L ÷ planned risk. Break-even = within ±0.1R (Settings). Win rate excludes break-evens. Drawdown limits are static, from the starting balance.

**Review routine:** Calendar → click the day → Daily review. Weekly and monthly reviews under Reviews. Analytics → Insights for patterns; Recurring mistakes and Rule adherence for discipline.

**Backups:** Trades → Export CSV.
